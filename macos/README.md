# 橙色卜卜 macOS 版

这是橙色卜卜独立项目的版本 28。安装包只包含 `bubu-orange`，不会安装、替换或卸载蓝色卜卜。

## 安装

1. 完整解压 `Orange-Bubu-macOS-Universal-28.zip` 或 `Orange-Bubu-macOS-Universal-Codex-Only-28.zip`。
2. 双击 `安装卜卜-macOS.command`。
3. 重新打开 Codex；安装器会自动选择橙色卜卜。

如 macOS 提示无法验证，请在“系统设置 → 隐私与安全”中选择“仍要打开”。要求 macOS 12.3+，兼容 Apple 芯片与 Intel Mac。

## 当前设计

- 正面圆形橙色卜卜，黑框眼镜、完整固定尺寸办公椅和橙色萝卜电脑标志。
- 椅子左侧是 219×1221 高清拟真产品材质荧光棒：独立的冷白磨砂外壳、青蓝发光管、金属反射、高光和动态泛光层；产品尺寸、12° 倾角与贴椅位置不变。
- 椅子左上方挂着“回到那一天”蓝色飞机票根：342×284 透明材质直接从批准设计稿提取，保留原始纸张纹理、边缘变化、阴影、印字与真实金属夹；只有额度数字和进度下划线动态绘制。
- 飞机与荧光棒是两个独立附件窗口。默认办公使用带真实金属夹的固定飞机；左拖时切换为无夹具、无木杆的独立飞行材质。荧光棒维持原来的 38×102 产品画布与屏幕锚点。
- 左拖播放约 0.8 秒的「回到那一天」：卜卜在椅上左歪、左看、眨眼，三片叶子延迟摇动，蓝色飞机票根从右向左只划过一次；该动作不显示荧光棒。右拖播放「椅边主唱 Live」：完整躺椅与电脑保持固定，卜卜面向椅架右侧的深蓝立麦唱歌，底座五颗蓝灯依次点亮；不显示外置荧光棒或飞机，松手恢复默认办公。
- 头顶面板使用泳池水纹蓝绿色半透明背景；不显示顶部 Codex 标题、剩余百分比、隐藏按钮、重置时间或横向进度条，只显示进行中任务与完整版的 BTC 行。
- 已运行结束的任务立即从面板移除；任务最多显示 5 行。
- 面板与荧光棒随宠物移动和同比缩放；面板箭头尖端保持在头顶正中约 14px。
- 双击卜卜可循环隐藏或显示面板。
