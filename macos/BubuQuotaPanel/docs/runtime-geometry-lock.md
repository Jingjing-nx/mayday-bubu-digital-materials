# 橙色卜卜运行时几何锁

当前正式构图以 `shared/pet/bubu-orange/qa/runtime-geometry-lock.json` 为基准。尺寸单位是宠物缩放为 `1.0` 时的逻辑点。

- 宠物与完整躺椅：`163 × 177`
- 默认面板：`224 × 75`
- 面板与宠物可见顶部间距：`14`
- 荧光棒：`29.83 × 80.07`
- 飞机票根：`61.23 × 51.025`

宠物缩放时，面板和配件只能进行等比缩放，禁止单独改宽、改高或叠加隐藏补偿系数。`14` 点的顶部间距保持不变。

面板、荧光棒和飞机票根统一使用校准后的“宠物与完整躺椅可见区域”作锚点；不得使用带大面积透明留白的 Electron 覆盖层边界。这样宠物拖动时三个元素会保持已批准的相对位置，不会被覆盖层高度抬到面板上方。

更改任何锁定值时，必须同时更新 macOS 的 `--self-test-runtime-geometry`、Windows 的 `-ValidateRuntimeGeometry`、共享 JSON 和用户批准的视觉基准。构建还会校验宠物、面板、荧光棒与票根的像素资产指纹，防止无意替换。
