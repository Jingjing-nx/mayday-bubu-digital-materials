# 橙色卜卜 Windows 版

这是橙色卜卜独立项目的版本 29。安装包只包含 `bubu-orange`，不会安装、替换或卸载蓝色卜卜。

## 安装

1. 完整解压 `Orange-Bubu-Windows-10-11-29.zip` 或 `Orange-Bubu-Windows-10-11-Codex-Only-29.zip`。
2. 双击 `安装卜卜-Windows.cmd`。
3. 安装器会关闭 Codex/ChatGPT；完成后重新打开即可。

支持 Windows 10/11、x64 与 ARM64；不需要管理员权限、Python、Node.js、.NET SDK 或 API Key。

## 当前设计

- 正面圆形橙色卜卜，完整固定尺寸办公椅与橙色萝卜电脑标志。
- 椅侧荧光棒使用 219×1221 高清拟真产品材质，外壳、发光管、金属反射、高光和动态泛光分层渲染；产品尺寸、12° 与贴椅构图保持不变。
- 椅子左上方挂着“回到那一天”蓝色飞机票根：342×284 透明材质直接从批准设计稿提取，保留原始纸张纹理、边缘变化、阴影、印字与真实金属夹；只有额度数字和进度下划线动态绘制。
- 飞机与荧光棒是两个独立 WPF 窗口。默认办公使用带真实金属夹的固定飞机；左拖时切换为无夹具、无木杆的独立飞行材质。荧光棒维持原来的 38×102 产品画布与屏幕锚点。
- 左拖播放约 0.8 秒的「回到那一天」：卜卜在椅上左歪、左看、眨眼，三片叶子延迟摇动，蓝色飞机票根从右向左只划过一次；该动作不显示荧光棒。右拖播放「椅边主唱 Live」：完整躺椅与电脑保持固定，卜卜面向椅架右侧的深蓝立麦唱歌，底座五颗蓝灯依次点亮；不显示外置荧光棒或飞机，松手恢复默认办公。
- 头顶面板使用泳池水纹蓝绿色半透明背景；只保留进行中任务与完整版 BTC 行。
- 已运行结束的任务立即移除，最多显示 5 个进行中任务。
- 面板和荧光棒跟随宠物移动、同比缩放，并兼容高 DPI 与多显示器。
- 双击卜卜可循环隐藏或显示面板。

## 项目隔离

- 安装目录：`%LOCALAPPDATA%\OrangeBubuPet`
- 登录启动名：`OrangeBubuQuotaPanel`
- 宠物目录：`%CODEX_HOME%\pets\bubu-orange`（未设置 `CODEX_HOME` 时使用 `%USERPROFILE%\.codex`）
- 卸载器只移除以上橙色项目文件，不触碰其他宠物项目。

`Codex-Only` 版不显示、也不请求 BTC 行情。`兼容安装-只装宠物.cmd` 可在 PowerShell 受限的公司电脑上只安装宠物。
